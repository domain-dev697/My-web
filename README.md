# Web Testing Sandbox

A personal web testing and learning playground built to experiment with frontend pages, backend API routes, and live deployment on Vercel.

## Project Structure

- `api/` — Backend API handlers (`_db.js`, `login.js`, `register.js`)
- `public/` — Frontend files (`styles.css`, `app.js`, and main HTML entry file)
- `package.json` — Project dependencies and scripts
- `vercel.json` — Vercel routing and deployment configuration
- `.gitignore` — Files and folders excluded from Git

## Notes & Attribution

- Built as a personal learning and testing project rather than a formal class submission.
- Boilerplate and API scaffolding were created with AI assistance, with custom styling, file organization, tweaks, and deployment managed personally.
- This project is for educational purposes only it only aims to learn how API work and fullstack web development
